## 如何使用本系列

1. **第一扇门**：从 **卷首卷《发现卷首》** 开始，它包含儒、道、释三家心法总纲，以及“极小入口”导航，帮你快速了解全系列框架。

2. **唯一操作入口**：接着阅读 **第0卷《每日十二问》**，它包含完整的十二问自省清单，扉页固定印有“**我做了吗？我开心吗？**”。

3. **分卷阅读**：根据你当下的情绪或需求（疲惫、迷茫、冲突、育儿焦虑等），直接选对应卷号。每卷均设有“**窜门小路**”引导你切换。

4. **日用功夫与经典**：若需泡脚晨茶、守心简轨、经典对照，查阅 **附录卷**。

5. **学习方式**：每卷独立，无需顺序阅读。每天睡前只问一条，一分钟就好。不问答案，只是问。**断了就回来。**

两者内容不同、定位不同、使用场景不同，互为补充，共同构成完整的自省工具生态。
